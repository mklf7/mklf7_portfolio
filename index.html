Description

Billeterie

Description

This french web-based event ticketing application was developed to manage the entire event lifecycle: event creation, seat management, ticket and invitation issuance, online sales, and access control via QR code. The platform integrates Stripe for payment processing and updates availability in real time to prevent overbooking.
The application was containerized using Docker. Docker Compose was used to orchestrate the various services (frontend, backend, database, Stripe) during development. Deployment was then performed on Kubernetes.

Technologies

Angular, NestJS, MongoDB, Socket.IO, Stripe, Docker, Docker Compose

SmartClinic.

Description

A web-based clinic management application designed to centralize the administrative, medical, and logistical operations of a healthcare facility. The platform integrates data analysis tools to support decision-making and monitor clinic activities.
The system is based on role and permission management: administrator (user management, analytics, and full access to the entire application), receptionist (scheduling and managing appointments between patients and physicians), physician (viewing patient records and managing their own appointments), pharmacist (recording purchases and managing medications), and logistics (tracking inventory and managing supplies).
This application improves service organization, operational traceability, and data utilization for facility management.

Technologies

React, Node.js, Express.js, MongoDB, Python, Streamlit, JWT, Git, GitHub

Traffic Offense Management

Description

A web-based application for managing traffic violations, designed for organizations responsible for monitoring and tracking offenses. The platform allows for vehicle registration, the entry and tracking of violations, and the management of fine status (paid or unpaid).
The application was designed using a service-oriented architecture (SOA), promoting modularity, maintainability, and scalability by separating the various functionalities into independent services.

Technologies

React, Node.js, Express.js, MongoDB, Git, GitHub
